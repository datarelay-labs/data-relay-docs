# 제품 상태

Data Relay 제품은 각각 독립적인 릴리스 주기를 가집니다. 이 통합 포털은 제품 역할을 요약하지만 각 제품의 상세 릴리스 문서를 대체하지 않습니다.

## Data Relay Link

공개 문서:

[https://link.datarelay.run](https://link.datarelay.run)

다음 정보는 Link 문서를 기준으로 합니다.

- 지원 플랫폼
- 현재 stable release
- Secure Remote Access 동작
- Controlled Egress 검증/릴리스 상태
- CLI 문법
- 설치 및 업그레이드
- 보안 경계와 알려진 제약사항

## Data Relay Control

공개 문서:

[https://control.datarelay.run](https://control.datarelay.run)

다음 정보는 Control 문서를 기준으로 합니다.

- 구현된 중앙 관리 기능
- 지원되는 정책 객체
- 인증 및 권한
- 배포 요구사항
- API/UI 동작
- 현재 릴리스 상태 및 제약사항

<Warning>
  Roadmap에 있다는 이유만으로 릴리스된 기능으로 판단하면 안 됩니다. Production 설계에서는 항상 각 제품의 전용 문서와 실제 릴리스 정보를 기준으로 하세요.
</Warning>

## 통합 포털 문서 원칙

이 사이트는 의도적으로 작게 유지합니다. 설치 명령, CLI reference, 상세 troubleshooting, 제품별 보안 설정은 여기에서 중복하지 않고 Link 또는 Control 문서에서 관리합니다.
