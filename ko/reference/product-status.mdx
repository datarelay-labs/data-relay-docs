# 제품 상태

Data Relay Link와 Data Relay Control은 서로 다른 repository, 구현, 릴리스 주기를 가집니다. 이 통합 포털은 두 제품의 역할을 균형 있게 설명하지만 각 제품의 전용 문서를 대체하지 않습니다.

## Data Relay Link

기준 문서:

[https://link.datarelay.run](https://link.datarelay.run)

다음 정보는 Link 문서를 기준으로 합니다.

- 현재 stable release와 지원 플랫폼
- Secure Remote Access 동작
- Controlled Egress 검증/릴리스 상태
- CLI 문법과 배포 절차
- lifecycle, diagnostics, backup/restore
- 보안 경계와 알려진 제약사항

## Data Relay Control

기준 문서:

[https://control.datarelay.run](https://control.datarelay.run)

다음 정보는 Control 문서를 기준으로 합니다.

- Connector, Credential, Source, Stream, Route, Destination 동작
- 구현된 Transform, Protection, Classification, Policy, Quarantine, Replay
- runtime delivery, checkpoint, evidence, health, audit
- 인증/RBAC 및 배포 요구사항
- 개발 브랜치의 Marketplace, Safe Change 등 신규 기능
- 현재 릴리스 상태와 알려진 제약사항

현재 Control 문서는 **Git tag로 확인된 `v1.0.0` stable release**와 이후 changelog lineage, 그리고 더 최신의 감사된 development branch를 구분합니다. 개발 브랜치에서만 확인된 기능은 immutable stable 기능이 아니라 implemented/under validation 상태로 문서화합니다.

## 현재 Link ↔ Control 연동 상태

<Warning>
  현재 Data Relay Control에는 Data Relay Link 등록, heartbeat, 정책 배포, 상태 동기화 프로토콜이 구현되어 있지 않습니다. 향후 실제 구현과 릴리스 문서가 확인되기 전까지 Control을 Link의 중앙관리 서버로 간주하면 안 됩니다.
</Warning>

## 통합 포털 문서 원칙

이 사이트는 작고 균형 있게 유지합니다. Data Relay 제품군 전체를 설명하고 어떤 제품이 필요한지 안내하는 역할만 담당합니다. 상세 설치 명령, CLI/API reference, troubleshooting, 제품별 보안 설정, 정확한 릴리스 보장은 Link와 Control 각 전용 문서에서 관리합니다.
