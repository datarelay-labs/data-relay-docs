# 제품 상태

Data Relay Link와 Data Relay Control은 **서로 다른 제품**입니다. 이 사이트는 두 제품을 소개하고 차이를 비교하는 공통 진입점이며, 설치 방법, 지원 기능, 제약사항, 릴리스 상태는 각 제품의 전용 문서를 기준으로 확인합니다.

## Data Relay Link

공식 문서:

[https://link.datarelay.run](https://link.datarelay.run)

Link 문서에서는 Secure Remote Access, 제한된 Outbound Connectivity, Service/Host 허용 정책, 배포, 운영, 현재 지원 범위를 확인합니다.

## Data Relay Control

공식 문서:

[https://control.datarelay.run](https://control.datarelay.run)

Control 문서에서는 Connector, Stream, Route, Destination, Filtering/Selection, Transformation, Protection, Data Delivery, Governance, Monitoring, 현재 지원 범위를 확인합니다.

<Note>
  Data Relay라는 이름을 공유한다고 해서 Link와 Control 사이의 Runtime Dependency나 중앙 관리 관계를 의미하지 않습니다. 각 제품은 자신의 전용 문서를 기준으로 독립적으로 평가합니다.
</Note>
