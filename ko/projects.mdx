# 프로젝트 소개

DataRelay Labs의 제품들은 공통적인 Relay 철학을 공유하지만, 서로 독립적이며 해결하는 문제도 다릅니다.

<CardGroup cols={2}>
  <Card title="Data Relay Link" icon="link" href="https://link.datarelay.run/">
    **사설망·폐쇄망·제한망을 위한 Secure Connectivity 제품입니다.**

    Network Reachability가 문제일 때 사용합니다. 외부에서 선택된 내부 서비스로 안전하게 접속하거나, 제한망 Host가 승인된 외부 Destination에만 접속하도록 합니다.
  </Card>

  <Card title="Data Relay Control" icon="sliders" href="https://control.datarelay.run/">
    **Enterprise Data Flow의 처리, Governance, 전달을 위한 제품입니다.**

    Application Data Movement가 문제일 때 사용합니다. 데이터를 한 번 수집하고 Route별로 처리·보호한 뒤 하나 이상의 Destination으로 전달합니다.
  </Card>
</CardGroup>

## 제품 비교

| | Data Relay Link | Data Relay Control |
| --- | --- | --- |
| 주요 문제 | Network Connectivity | Enterprise Data Integration / Delivery |
| 이동 대상 | Connection | Application Data / Event |
| 대표 흐름 | 외부 → 내부 서비스, 제한망 Host → 승인된 Internet Destination | Source → Stream → Routes → Destinations |
| 핵심 제어 | 어떤 Host/Service에 연결할 수 있는가 | 어떤 Record/Field를 어디로 어떤 형태로 전달하는가 |
| 대표 규모 | 몇 대에서 수십 대 수준의 소규모 환경 | Enterprise Data Flow Pipeline |
| 제품 의존성 | 없음 | 없음 |
