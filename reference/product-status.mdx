# Product Status

Data Relay Link and Data Relay Control are **separate products**. This site provides a common introduction and comparison only; the dedicated product sites are authoritative for installation, supported features, limitations, and release status.

## Data Relay Link

Authoritative documentation:

[https://link.datarelay.run](https://link.datarelay.run)

Use the Link documentation for secure remote access, restricted outbound connectivity, service/host allow rules, deployment, operations, and current supported behavior.

## Data Relay Control

Authoritative documentation:

[https://control.datarelay.run](https://control.datarelay.run)

Use the Control documentation for connectors, streams, routes, destinations, filtering/selection, transformation, protection, data delivery, governance, monitoring, and current supported behavior.

<Note>
  Sharing the Data Relay name does not imply a runtime dependency or centralized management relationship between Link and Control. Each product should be evaluated from its own documentation.
</Note>
