# Product Status

Data Relay products have separate release cycles. This platform portal summarizes their roles but does not replace each product's release documentation.

## Data Relay Link

Current public documentation:

[https://link.datarelay.run](https://link.datarelay.run)

The Link documentation is the source of truth for:

- supported platforms;
- current stable release;
- Secure Remote Access behavior;
- Controlled Egress qualification status;
- CLI syntax;
- deployment and upgrade procedures;
- security boundaries and known limitations.

## Data Relay Control

Current public documentation:

[https://control.datarelay.run](https://control.datarelay.run)

The Control documentation is the source of truth for:

- implemented centralized management features;
- supported policy objects;
- authentication and authorization;
- deployment requirements;
- API/UI behavior;
- current release status and limitations.

<Warning>
  Do not treat a roadmap item as a released capability. Always use the dedicated product documentation and immutable release information when planning production deployment.
</Warning>

## Platform documentation policy

This site intentionally stays small. Detailed installation commands, CLI references, troubleshooting procedures, and product-specific security controls belong in the Link or Control documentation rather than being duplicated here.
