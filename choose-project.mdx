# Choose by Problem

Select the problem closest to your environment. Each card opens the dedicated product site.

<CardGroup cols={2}>
  <Card title="I need remote access behind NAT/firewalls" icon="arrow-right-to-bracket" href="https://link.datarelay.run/">
    **Data Relay Link — Secure Remote Access** publishes only the SSH, HTTP, HTTPS, or custom TCP services you choose from systems that cannot accept normal inbound connections.
  </Card>

  <Card title="I need controlled Internet access from a restricted network" icon="arrow-up-right-from-square" href="https://link.datarelay.run/">
    **Data Relay Link — Controlled Egress** lets restricted hosts use approved HTTP/HTTPS destinations through source, FQDN, port, and fail-closed policy controls.
  </Card>

  <Card title="I need to collect, process, and deliver enterprise data" icon="arrows-left-right" href="https://control.datarelay.run/">
    **Data Relay Control** collects data once, applies route-specific Transform, Protection, and Policy, then delivers it to one or many destinations.
  </Card>

  <Card title="I am not sure which product fits" icon="circle-question" href="/projects">
    Compare Data Relay Link and Data Relay Control by problem, data path, operating model, and product boundary.
  </Card>
</CardGroup>

<Note>
  Data Relay Link and Data Relay Control are independent products. Control is not a centralized manager for Link, and Link is not a network transport component inside Control.
</Note>
