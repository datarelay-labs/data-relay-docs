# DataRelay Labs

**Open-source tools for secure connectivity, controlled data movement, and enterprise data delivery.**

DataRelay Labs is the common home for independent projects that solve practical connectivity and data-delivery problems. Each product keeps its own runtime, documentation, release lifecycle, and operational boundary.

<Note>
  Start with the problem you need to solve. Data Relay Link and Data Relay Control are separate products; neither one is required to use the other.
</Note>

## Current products

<CardGroup cols={2}>
  <Card title="Data Relay Link" icon="link" href="https://link.datarelay.run/">
    Secure connectivity for small environments: publish selected private services behind NAT/firewalls and provide controlled outbound access from restricted networks to approved Internet destinations.
  </Card>
  <Card title="Data Relay Control" icon="sliders" href="https://control.datarelay.run/">
    Enterprise Data Control Gateway using a **One Stream → Many Routes → Many Destinations** model for collection, route-specific processing, governance, protection, and delivery.
  </Card>
</CardGroup>

## Built to grow as a project family

`datarelay.run` is the organization portal. Individual products live on their own product sites, such as `link.datarelay.run` and `control.datarelay.run`. Future DataRelay Labs projects can be added here without turning the existing products into components of one bundled platform.
